## 아키텍처 결정 사항

### deck.gl + MapLibre 통합: MapboxOverlay (overlaid 방식)

deck.gl 공식 문서에서 추천하는 방식. Map이 루트 컴포넌트이므로 MapLibre의 NavigationControl 등 네이티브 컨트롤을 그대로 사용 가능.

```tsx
import {Map, useControl} from 'react-map-gl/maplibre';
import {MapboxOverlay} from '@deck.gl/mapbox';

function DeckGLOverlay(props: DeckProps) {
  const overlay = useControl<MapboxOverlay>(() => new MapboxOverlay(props));
  overlay.setProps(props);
  return null;
}
```

reverse-controlled 방식(DeckGL이 루트)은 MapLibre 컨트롤 사용 불가하므로 채택하지 않음.

### 베이스맵: VersaTiles Neutrino

`@versatiles/style`의 `neutrino()` 함수로 스타일 객체 생성. 타일 소스는 `tiles.versatiles.org` (무료, API 키 불필요).

**주의**: 브라우저에서 sprite/glyphs/tiles URL이 상대 경로로 생성됨 → `https://tiles.versatiles.org` 절대 URL로 강제 변환 필요.

### 사이드바: CSS Flexbox 화면 분할

shadcn `<Sidebar>`는 overlay/fixed 방식이라 사용하지 않음. Flexbox로 sidebar(320px) + map(flex:1) 분할. sidebar width를 CSS transition으로 0px ↔ 320px 토글. 지도가 실제로 리사이즈됨.

### PMTiles 행정구역 오버레이

`pmtiles` 패키지로 프로토콜 등록 후 MapLibre 네이티브 소스/레이어로 추가.

소스: `https://raw.githubusercontent.com/vuski/assets/refs/heads/main/map/adm.pmtiles`

레이어 구조:
- `sido` / `sido_line` (시도, zoom 1~14)
- `sgg` / `sgg_line` (시군구, zoom 7~14)
- `emd` / `emd_line` (읍면동, zoom 10~14)
