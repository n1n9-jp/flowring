# 20260320 — Lambda API 전환 및 전체 모드 구현

## 개요

Snowflake SQL API 직접 호출에서 AWS Lambda (Athena) + CloudFront 구조로 전환하고,
'이동 전체'/'순이동 전체' 모드를 추가하여 전국 단위 인구이동 시각화를 구현함.

---

## 1. 데이터 소스 전환: Snowflake → Lambda (Athena)

### 아키텍처

```
클라이언트 → CloudFront (캐시 86400초) → API Gateway HTTP API → Lambda → Athena
                                                                   ↓ (대용량)
                                                              S3 → presigned URL → 클라이언트
```

### 쿼리 함수 추상화

- `src/lib/query-functions.ts` — Snowflake 직접 호출 (삭제 금지, 백업/참조용)
- `src/lib/query-functions-lambda.ts` — Lambda GET 호출 (현재 사용)
- 4개 컴포넌트에서 import만 바꾸면 전환 가능한 구조

### Lambda 엔드포인트 (domesticMigrationSouthKoreaRenewal/cdk)

| 엔드포인트 | 테이블 | 용도 |
|---|---|---|
| `/flow` | flow | 이동 지역 (기존 호환 + yearFrom/yearTo 확장) |
| `/netflow` | netflow | 순이동 지역 (기존 그대로) |
| `/flow-all` | flow | 이동 전체 (신규) |
| `/netflow-all` | netflow | 순이동 전체 (신규, `AND ori < des` 최적화) |

### 대용량 응답 분기

- **5MB 이하**: JSON/Arrow 직접 응답 (CloudFront 캐싱 혜택)
- **5MB 초과**: Arrow IPC → S3 업로드 → presigned URL 반환 (API Gateway 10MB/Lambda 6MB 제한 우회)
- 클라이언트: 응답에 `url` 필드가 있으면 S3에서 Arrow IPC 다운로드 → `tableFromIPC` 파싱

### Athena 결과 S3 직접 읽기

- 기존: `GetQueryResults` 페이지네이션 (1000행씩, 수십만 행 → 60초 타임아웃)
- 변경: `GetQueryExecution`에서 결과 S3 경로 획득 → S3에서 CSV 직접 읽기 → JSON 변환
- fallback: S3 읽기 실패 시 기존 페이지네이션

### CDK 변경 (data-api-stack.ts)

- Lambda: 메모리 2048MB, 타임아웃 120초
- API Gateway: `/flow-all`, `/netflow-all` 라우트 추가
- CloudFront: origin timeout 60초, cache policy `queryStringBehavior: all()`
- S3 결과 버킷: CORS 설정 추가 (`allowedOrigins: *`, `GET`)
- 캐시 헤더: `max-age=86400, s-maxage=86400, stale-while-revalidate=3600`

## 3. 전체 모드 (flow-all / netflow-all)

### UI 구조

- 1단계: 데이터 카테고리 선택 (순이동, 이동, 순이동 전체, 이동 전체)
- 2단계: Tabs로 옵션 선택
- 조회 후 지도 hover → 오른쪽 패널에 AG Grid 테이블 + 막대 그래프

### 쿼리 파라미터

- yearFrom, yearTo, counterpartyUnit (시도/시군구/읍면동), ageGroup, gender
- 응답: `{ori, des, flow}` 3컬럼

### hover 감지: GeoParquet → GeoJSON

- `public/emd.parquet` (2.7MB, 읍면동 폴리곤)
- `parquet-wasm` + `apache-arrow`로 로딩 → WKB → GeoJSON 변환
- MapLibre `geojson` source + 투명 fill 레이어 (zoom 무관)
- 하이라이트: counterpartyUnit에 따라 `emdcd`/`sggcd`/`sidocd` 기준 fill 하이라이트
  - 시군구 선택: 같은 sggcd의 읍면동 전부 하이라이트
  - 시도 선택: 같은 sidocd의 읍면동 전부 하이라이트

### netflow-all 최적화

- `AND ori < des` 조건으로 데이터량 절반
- 클라이언트에서 선택 지역이 ori/des 어디든 양쪽 체크, 방향에 따라 flow 부호 반전

## 5. 이동(flow) 관내 처리

### 관내 판정 로직

- `ori === des` → 관내
- 한쪽이 시군구(5자리), 다른 쪽이 읍면동(10자리)일 때 시군구로 올려서 같으면 → 관내
- `isSameRegion()` 함수: 자릿수 기반 판정 (시도 2자리, 시군구 5자리, 읍면동 10자리)

### 처리

- direction을 `"관내"`로 변경하여 테이블에 표시
- 전입+전출 동시 요청 시 관내 행 중복 제거
- 지도에서는 관내 제외 (경로 없음)
- 이동 전체: `ori === des` 행 필터 제거
