## 1. SvgMoveIndicator 이식

### 소스 (next_exer02) → 타겟 (maplibre-test) 차이점

| 항목 | 소스 | 타겟 |

| hover 트리거 | deck.gl GeoJsonLayer `onHover` | deck.gl GeoJsonLayer `onHover` (동일 방식으로 전환) |
| 데이터 구조 | `moveMap_oriBased` Map | `flowAllFilteredData` + `admcenterMap` |
| 스타일링 | styled-components | Tailwind + inline style |

### 컴포넌트 구조

`src/components/map/svg-move-indicator.tsx`:
- Props: `mapRef`, `selectedRegion`, `filteredData`, `admcenterMap`, `direction`, `isDark`
- render body에서 `reCalculateRank()` + `redrawAll()` 직접 호출 (소스와 동일 패턴)
- `map.on("move")` 구독으로 zoom/pan 시 SVG 좌표 실시간 동기화

### SVG 드로잉 함수

- `reCalculateRank()` — top12 추출, ratio 계산
- `redrawAll()` — SVG clear + arrow marker + drawInfoCircle
- `drawInfoCircle()` — 좌표 변환 + adjustRatioBarLocation + 각 요소 그리기
- `drawOriNm()` — 중심 지역명 + "{direction} 인구 순위"
- `drawOriToDesLine()` — 실선 + 화살표 (유입/유출 방향 반전)
- `drawPieChart()` — 원형 파이 슬라이스 (d3.arc)
- `drawDimLine()` — 지시선 + "N위 지역명 NNN명" 라벨 (4분면 배치)
- `adjustRatioBarLocation()` — 겹침 조정 (800회 반복) + 교차선 해소

### 화살표 방향

- **유출/순유출**: 중심 → 외부 방향 (기존)
- **유입/순유입**: 외부 → 중심 방향 (반전)
- 화살표는 선의 중간 허리에 배치 (투명 선분 + `marker-end`)

### 다크/라이트 모드

`isDark` prop으로 배경지도에 따라 색상 전환:

| 요소 | 다크 (dark-matter, eclipse, shadow, esri-imagery) | 라이트 |
|------|------|------|
| 선/원/글씨 | white | black |
| 지시선 | #cccccc | #666666 |
| 파이 차트 | 동일 (빨간색) | 동일 |

## 2. Hover 반응성 최적화 — 핵심 변경

### 문제

MapLibre GeoJSON source + `queryRenderedFeatures` + `setFilter` 방식은
전국 읍면동 폴리곤(수천 개) 히트테스트가 느려 hover 반응성이 원래 프로젝트 대비 현저히 떨어짐.

### 해결: MapLibre GeoJSON → deck.gl GeoJsonLayer 전환

| 항목 | Before (느림) | After (빠름) |
|------|------|------|
| 폴리곤 렌더링 | MapLibre GeoJSON source + 3개 레이어 | deck.gl GeoJsonLayer 1개 |
| hover 감지 | `queryRenderedFeatures` (CPU 폴리곤 히트테스트) | deck.gl GPU color picking |
| 색상 변경 | `setFilter` (전체 GeoJSON 스캔) | `getFillColor` + `updateTriggers` (GPU 즉시 반영) |
| 지도 이벤트 | `onMouseMove` + rAF throttle | deck.gl `onHover` (내장 최적화) |

### deck.gl GeoJsonLayer 구성

```typescript
new GeoJsonLayer({
  id: "emd-hover",
  data: emdGeojson,
  pickable: true,
  beforeId: admLayersReady ? "emd-line" : undefined,  // PMTiles 라인 아래 배치
  getFillColor: (d) => {
    const code = Number(d.properties?.[codeKey]);
    if (code === hoverCode) return [23, 115, 58, 255];     // hover 지역
    if (top10Set.has(code)) return [174, 242, 2, 180];     // top10 카운터파트
    return [0, 0, 0, 0];                                    // 투명
  },
  onHover: handleEmdHover,
  updateTriggers: { getFillColor: [hoverCode, top10Set] },
})
```

### interleaved 모드

`DeckGLOverlay`에 `interleaved: true` 설정:
- deck.gl 레이어를 MapLibre 레이어 사이에 삽입 가능
- `beforeId: "emd-line"`으로 PMTiles 행정구역 라인이 hover 면 위에 그려짐
- 배경지도 전환 시 `admLayersReady` state로 `beforeId` 조건부 적용

### store 사전 인덱스 (O(1) lookup)

**Before**: 매 hover마다 rawData 전체(수만 건) filter → map → sort
**After**: 데이터 수신 시 `buildIndex()`로 `Map<code, entries[]>` 미리 빌드, hover 시 O(1) lookup

```
flow-store.ts:
  setFlowAllRawData(data) → buildIndex(data, false) → flowAllIndex
  setNetflowAllRawData(data) → buildIndex(data, true) → netflowAllIndex

  setSelectedRegion(code) → index.get(code) → O(1) → filter/sort 소수 항목만
```

인덱스 구조:
- `inbound: Map<regionCode, {counterpart, flow}[]>` — 전입/순유입용
- `outbound: Map<regionCode, {counterpart, flow}[]>` — 전출/순유출용
- netflow-all: `ori < des`이므로 양방향 인덱스 (flow 부호 반전 포함)

## 4. netflow-all SQL 수정

### 문제

`AND ori < des`를 원본 읍면동(10자리) 코드에서 적용 후 시군구(5자리)/시도(2자리)로 GROUP BY →
같은 시군구 쌍이 `(A,B)`와 `(B,A)` 양쪽으로 결과에 포함됨.

### 해결

`ori < des`를 서브쿼리 바깥(집계 후)에 적용:

```sql
SELECT ori, des, flow FROM (
  SELECT cast(ori/100000 as bigint) AS ori,
         cast(des/100000 as bigint) AS des,
         SUM(flow) AS flow
  FROM netflow
  WHERE year BETWEEN ... ${genderCond} ${ageCond}
  GROUP BY cast(ori/100000 as bigint), cast(des/100000 as bigint)
)
WHERE ori < des
ORDER BY ABS(flow) DESC
```

### 클라이언트: 동일 counterpart 합산

`setSelectedRegion`에서 시도 통합(`mergeRows`) 후 `ori < des`가 깨져서 같은 counterpart가 2행 나올 수 있음 → merged Map으로 합산 후 정렬.

## 5. 배경지도 전환 안정화

### 문제

배경지도 변경 시 MapLibre가 모든 소스/레이어를 제거하는데:
1. GeoJSON source(emd-geojson) 재추가 누락 → hover 감지 불가
2. PMTiles 레이어 재추가 타이밍 문제 → deck.gl `beforeId` 실패

### 해결

1. **emd-geojson → deck.gl 전환**으로 MapLibre 레이어 의존성 제거
2. `admLayersReady` state:
   - 스타일 변경 버튼 클릭 → `false` → deck.gl `beforeId` 없이 렌더
   - `idle`/`load` 이벤트 → PMTiles 레이어 재추가 → `true` → `beforeId: "emd-line"` 적용
