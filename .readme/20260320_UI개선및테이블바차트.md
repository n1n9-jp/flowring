## 1. SVG 시각화 타입 정리

### any 제거

`svg-move-indicator.tsx`의 모든 `any`를 구체적 타입으로 교체:
- `Point` — 스크린 좌표 (px)
- `RankEntry` — 순위 항목 (descd, desnm, desxy, popu, ratio, rank, angle, adjustedOuter 등)
- `Top12Data` — top12 계산 결과 (oricd, orinm, orixy, top10)
- `DimEntry` — 지시선 정렬용 (index, dimLineDes)
- `D3Svg` — d3.select(svgElement) 반환 타입

### React 19 호환

- `useRef` → `useState`(svgEl용 callback ref), `useMemo`(top12Data 순수 함수화)
- render body의 ref 접근 → `useEffect`로 이동
- `React.memo`로 부모 re-render 차단 (blinkTime state 전파 방지)

## 2. SVG 텍스트 버퍼 (White/Black Buffer)

- `appendBufferedText()` 헬퍼: 같은 텍스트를 `stroke`(두꺼운 윤곽) + `fill`(실제 텍스트) 2회 렌더
- 다크 모드: `bufferColor = "black"`, 라이트 모드: `bufferColor = "white"`
- 제목(drawTitle), 지시선 라벨(drawLineAndText) 모두 적용

## 3. 원문자 순위 라벨

- 기존: `"1위 경기도 안산시 1,234명"` 텍스트

## 5. 깜빡임 애니메이션 (Blink)

### 타이밍 상수 (export, SVG + 지도 fill 공유)

- `BLINK_CYCLE = 6` (초)
- `BLINK_DELAYS = [1.5, 3, 4.5]` (각 순위별 시작 시점)
- `BLINK_PATTERN: [opacity, duration][]` — 사용자 조정 가능

### 아크 깜빡임

- `getBlinkOpacity(timeSec, rankIndex)` → 1~3위 아크에 opacity 적용
- 1~3위: 진한 색상(`rgb(242, 45, 10)`), 나머지: 연한 색상
- 1~3위: 아크 바깥에 strokeColor 테두리 아크 덧대기 (두께 20%)

### 텍스트 바운스

- `getBlinkBounce(timeSec, rankIndex)` → Y 오프셋 (위-제자리-위-제자리)
- 원문자 + 라벨 텍스트 동시 바운스

### 지도 fill 동기화

- `map-container.tsx`에서 150ms `setInterval` → `blinkTime` state
- `getFillColor`에서 1~3위 지역의 alpha를 `getBlinkOpacity`로 제어
- `selectedRegion` 변경 시 타이머 리셋

## 6. AG Grid 인라인 바 차트

### 전체 모드 (순이동전체/이동전체)

- 컬럼: 지역 + 수량 + 비율(%) 분리
- `getRowStyle`로 row 전체 배경에 gradient 바 (상하 3px offset)
- 색상: `#a6db44`

### 기존 모드 (순이동/이동)

- `getRowStyle`로 row 배경 바 (체크박스 40px offset)
- 순이동: 양수 왼→오(`#a997cc`), 음수 오→왼(`#be7070`)
- 이동: 전입(`#a997cc`), 전출(`#be7070`, 오→왼), 관내(`#a6db44`)
- 비율 컬럼: 순이동만 (양수: 순유입합 기준, 음수: 순유출합 기준)

### 테이블 헤더 통계

- 전체 모드: `OO건 | 총이동량 : OO명`
- 순이동: `OO건 | 순유입 : OO명, 순유출 : OO명`
- 이동: `OO건 | 관내 : OO명, 전입 : OO명, 전출 : OO명`

## 7. 오른쪽 패널 개선

### 패널 폭 분리

- `PANEL_WIDTH = 650` (기존 모드)
- `PANEL_WIDTH_ALL = 350` (전체 모드)

### 지역 고정 기능

- `isRegionLocked` state + `toggleRegionLock` action (flow-store)
- `setSelectedRegion`에서 `isRegionLocked`면 즉시 return
- UI: "고정 (F)" / "고정 해제 (F)" 토글 버튼 (검은색/회색 배경)
- 키보드 F 단축키 (input/textarea 제외)
- `clearSelectedRegion` 시 lock 해제

### 헤더 지역명

- 전체 모드: `{selectedRegion.name} — 기준 지역`
- 기존 모드: `netflowQueryParams.desName` / `flowQueryParams.regionName`
- 조회 시 store에 전체 파라미터 저장

## 8. 옵션 상태 유지

- 4개 request 컴포넌트에서 `useState` 초기값을 store의 `queryParams`에서 복원
- 조회 성공 시 전체 파라미터를 store에 저장
- 탭 전환 후 돌아와도 직전 선택값 유지
- 연도 입력: `onBlur`에서 2001~2024 범위 clamp, 기본값 "2024"

- 탭 순서: 순이동전체 → 이동전체 → 순이동 → 이동 (초기값: netflow-all)
